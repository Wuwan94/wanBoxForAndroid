# wanBox 下一版发行说明草稿（基于 v3.0.10，分支 optimize/phase2）

> 说明：`.github/workflows/release.yml` 以整份 `RELEASE_NOTES.md` 作为发布正文，而该文件当前绑定 v3.0.10 正式版。为避免改动 v3.0.10 的发布内容，本节先放在此草稿中；发布下一版时，把下面「界面与精简」整节并入新版 `RELEASE_NOTES.md`。版本号与版本码须按 `tools/version_code.py` 的规则生成，本分支未改任何版本元数据。

## 界面与精简

### 视觉（方向 A「奶糖猫」）
- 主题迁移到 Material 3（Material Components 1.8 → 1.12，`Theme.Material3.*`），默认标志色为奶茶粉；浅色、深色两套同步调整。
- 修复「外观主题色选了不生效」：旧版启动时会强制改回浅灰主题，现改为一次性迁移，之后保留用户选择。
- 四大主页的固定灰色改为跟随主题；布局中写死的颜色清零，Kotlin 中的 `parseColor` 改为主题色，修复小组件节点选择弹窗等在深色/浅色下的显示问题。
- 圆角统一：卡片 16dp、小控件 12dp、对话框 28dp，并统一间距刻度。
- 图标统一为圆润线性风格（71 处替换）。
- 首页连接按钮改为 164dp 圆形视觉中心，四态分明：未连接 / 连接中（环形进度）/ 已连接（显示运行时长）/ 异常，每态配猫耳吉祥物表情，状态切换与换节点时有轻量回弹动效。
- 节点页「更多」菜单标题改用字符串资源，不再写死中文；关于页「版本 / 检查正式版 / 检查预览版」合并为一行。

### 行为修复
- 首页「规则 / 全局 / 直连」只切换路由模式，不再关闭分应用代理或改写其绕过设置。之前被误关的分应用代理不会自动恢复，需到分应用页重新开启。
- 仅打开分应用页不再自动开启分应用代理；页面如实显示「关闭」状态。
- 节点页恢复统一「+」入口：手动添加、扫码、剪贴板导入、文件导入。
- 首页新增「更新订阅」按钮。

### 连接稳定性
- Root 模块看门狗：核心异常退出后最多重启 5 次，退避 1/2/4/8/16 秒，不会无限重启；退出原因与重试次数落盘。
- 断线原因分五类记录：核心退出、网络切换、节点失效、TUN 失败、未知。
- 网络切换后验证数据面是否真的通，失败重试，必要时重建 TUN（有频率上限）。
- 节点健康检查：默认仅提示；可选「同组自动切换」（默认关闭）；「连接与核心」页提供「切到同组最快节点」。
- 管理端读取模块状态单次失败不再直接显示「未连接」，改为退避重试；连续失败才显示「异常」。
- 日志页可查看模块最近事件；修复节点切换耗时事件被静默丢弃的问题。

### 流畅度
- 节点列表加载移出主线程；全部分组页的禁用状态改为按组批量查询。
- 列表绑定时不再重复读取设置；3 处整表刷新改为只刷新变动行；首页每秒刷新只更新有变化的控件。
- geoip/geosite 首次解压移到后台，不再阻塞冷启动。
- 新增可选的 Macrobenchmark / Baseline Profile 模块（构建时加 `-PwanboxBenchmark=true`，默认构建不受影响）。

### 本次未做事项及原因
- `baseline-prof.txt` 暂未提交，后续版本补充。
- 设置读取内存缓存未做：后台进程也会写同一存储，需先实现跨进程失效，否则可能读到旧值。
- 超过 1000 个节点时的 DiffUtil 优化、个别页面剩余的主线程读取未处理。
- 少数图标（返回、发送、重做、取消、完成、二维码等）暂无线性版本；工具页信息结构未调整。
