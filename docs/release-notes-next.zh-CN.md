# v3.0.17-preview.2 发行说明

**状态：未发布的稳定性预览版候选。**

本版是两路借鉴移植批次的合集，面向已 Root 的 Android 12+ arm64 设备：核心稳定性与故障转移、订阅自动更新、智能分流、冷启动秒连、策略组混搭/锁定/优先级、停核可编辑与脱敏诊断包、按网络规则、路由规则指定策略组。稳定版 `v3.0.14` / 正式元数据 `2026` 与 sing-box pin `v1.15.0-alpha.13-reF1nd` 均未改变；预览名为 `3.0.17-preview.2`，APK `versionCode=10162`，Root 模块码 `2032`（preview.1 为 `10156` / `2031`）。

## 本版更新

1. **核心稳定性与故障转移**：DNS `Success` 回调补发完成信号；测速间隔默认 0 毫秒改为 1000 毫秒；切换节点改走热切换，确认失败明确报错、不静默回落全量重建；延迟惩罚 uint16 回绕修为饱和封顶 65000，连续两次失败清历史；单步建连超时固定 3 秒（仅有后备候选时约束），黑洞节点 3 秒即转移且不中断现有连接；切网重置路由器 DNS/HTTP 连接池；组内成员切换后落地 IP 缓存立即失效。
2. **订阅自动更新**：间隔改为弹窗设置（预设 15/30 分钟、1/3/6/12 小时、24 小时/1 天 + 自定义单位与人性化摘要），最小间隔 15 分钟；进订阅页与连接成功时补更到期订阅，补更尊重失败退避。主进程调度迁移待用户拍板，本版未做。
3. **智能分流与规则集缓存**：0 规则占位 `.srs` 缓存不再被当作有效缓存，改为校验实际规则条数、空占位重新生成；新增 19 项系统组件排除名单（供未来分类层使用，本版不在用户显式规则上套用）；`local:` 输入仍明确拒绝。
4. **冷启动秒连与快速转移**：首轮探针快成员就绪即用，不再等整轮；过期历史不再压过新鲜历史；黑洞转移覆盖 UDP（3 秒超时、两次清史），故障转移不中断现有连接；探测间隔仍 ≥10 秒、空闲 ≥30 分钟。
5. **策略组混搭与组隔离**：类型新增“混合（分组 + 节点）”，上限与名称正则、实时成员计数；两组共享成员不再串线，隔离链不再泄漏进顶层选择器；`BalancerBean` v5→v6。
6. **策略组手动锁定、统计页与主页横幅**：统计页点按成员行即锁定，锁定后改发 selector、不再自动切换，不可用时红字提示，可随时恢复自动；统计页展示失败数与最近报错，“整组测速”改为一键“立即全部检查”；主页新增策略组横幅（30 秒刷新，点进统计页）。
7. **策略组「按优先级顺序」与节点优先级**：新增并列策略，按层级嵌套 urltest 择优，回切不断连接；节点优先级二级页支持拖拽排序、按延迟排序与移除（散装离组、分组来源进排除表且只在优先级模式生效）；`BalancerBean` v6→v7。
8. **停核可编辑与脱敏诊断包**：核心停止时节点、订阅、路由与策略组照常浏览、编辑与测速（默认行为，无开关）；停核测速走 Root 短生命周期测试会话，插件出站节点暂不支持；设置页一键导出脱敏诊断包（默认 Download 目录；服务器地址与 SNI 打码、公网 IP 只留前两段、损坏 JSON 省略原文、远程规则只列元数据、不含用户备份；导出前明示残留风险）。
9. **按网络规则、共享流量与分应用按用户**：“按网络”规则与 F1 智能启停合并为一张表（上限 5 条；按 SSID/网关/CIDR/出口类型匹配，首条胜出；动作暂停/直连/保持，新规则默认保持；不申请定位权限）；共享流量只接 eBPF 路径、默认关闭，TUN 下不支持；分应用按用户（键 `<userId>:<package>`），白名单为空时不代理任何应用。
10. **路由规则可指定策略组**：按稳定实体 ID 引用，改名不丢引用，与节点出站互斥；引用不存在的组按缺失出站处理（告警后丢弃，不静默回落主代理）；删组时有引用则阻止并可跳到引用规则；Room 10→11。
11. **热更新契约测试与守卫泄漏修复**：只补测试、不动实现（13 项 Go 契约测试 + 10 项委托脚本测试）；测试暴露 1 项真缺陷并已修——备份创建失败时 pref 9001 黑洞守卫泄漏，现已在两处失败返回前释放守卫。
12. **本轮不做的事**：O8 自选统一引擎不采（上游未收敛，需求由 O3+O1+O7 组合覆盖）；N8 eBPF 入站只做可行性评估，不实现；O5 主进程调度迁移待用户拍板，未做。
