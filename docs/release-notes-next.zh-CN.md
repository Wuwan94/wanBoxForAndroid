**状态：未发布的稳定性预览版候选。**

## 本版更新

1. **组成员单一真相**：节点归属是组成员的唯一依据，组草稿只负责顺序与 URLTest 参数。保存时新加入的节点在同一事务内移入该组，从普通分组移除的节点移到「未分组」；订阅组只可调整顺序与参数。订阅更新新增的节点自动追加到成员末尾；组列表计数、运行配置与导出配置的组成员三者一致。
2. **订阅撞名不再断连**：构建时预留所有分组与组草稿的名称，同名订阅节点自动加后缀；仍冲突时提示「组名与节点名称重复，请重命名冲突条目后重试」。
3. **选中节点显式回落**：选中节点被移出主组时，Selector 显式回落到首个成员，并在模块确认后同步界面选中项。
4. **放弃未完成编辑**：恢复因基线失效失败时，可在策略组页放弃未完成编辑，恢复本机组配置、清除恢复标记并按当前配置重建模块。
5. **设置与编辑器口径一致**：「切换时中断现有连接」在组设置页与编辑器统一锁定关闭并明确说明；已有组类型锁定时提示到组设置页修改。
6. **维护性清理**：组草稿读取不再在快照事务内逐组查库；移除「兼容旧版」导出（仍禁用）未使用的提示字符串。
