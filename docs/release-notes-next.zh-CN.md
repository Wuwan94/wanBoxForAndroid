# v3.0.16-preview.3 发行说明（候选）

**状态：未发布的稳定性预览版候选。**

本版汇总四个批次的成果，面向已 Root 的 Android 12+ arm64 设备：策略组浏览/选择/测速、界面与 Root 模块能力对齐、图形化策略组编辑与统一资源页、备份与迁移规范化，并含网关缓存深拷贝修复。稳定版 `v3.0.14` / Root 模块码 `2026` 与 sing-box pin `v1.15.0-alpha.13-reF1nd` 均未改变；预览名为 `3.0.16-preview.3`，APK `versionCode=10148`，Root 模块码 `2029`。

## 本版更新

1. **图形化策略组编辑**：策略组可在界面内图形化编辑，增删 Selector / URLTest 组成员、调整 URLTest 测速参数，保存后经 Root 模块应用链校验并生效，校验不过明确拦截。成员引用以稳定实体 ID 保存并按直接/链式节点规则解析为运行时 tag，引用缺失时明确报错。同时修复既有问题：此前在组设置页保存任意修改，都会把该组的 URLTest / 负载均衡模式静默重置为手动选择模式，本版起模式按编辑结果如实保存。
2. **策略组浏览、选择与测速**：新增策略组页面，直接从运行中的控制器快照浏览各策略组及其成员，可在 Selector 组内切换当前节点并回读验证，也可对成员逐个测速，失败成员带明确标注。
3. **统一资源页与重名消歧**：本地节点与订阅统一在同一资源视图中呈现，节点页新增「更新当前订阅 / 更新所选订阅 / 更新全部订阅」三个入口，带进度条与失败清单反馈。重名节点与订阅在显示层消歧：先显示为「名称（来源）」，仍重名再加实体 ID 后缀；消歧只影响显示，改名不会改变实体 ID、组成员与路由引用。
4. **备份与迁移规范化**：恢复备份前先展示必读说明（来源/目标版本、兼容范围、影响与恢复办法），确认后才开始转换；旧格式备份导入时，被缺省补齐的字段会逐项列出，不再静默补齐；恢复结果报告把「数据库已恢复」与「核心配置已应用」分开呈现，失败时给出回滚状态与恢复指引。「兼容旧版」导出暂未开放：尚无经过真实旧版读取器验证的写入器，本版禁用入口并明确说明；现有备份导出与旧格式导入不受影响。
5. **模块退出诊断上屏**：设置页根模块区新增退出诊断，展示模块进程的重试次数、退出事件、最近一次退出原因与时间。此前这些信息模块已上报但界面无处可见，排查模块异常退出时只能翻日志。
6. **网关缓存深拷贝**：自动启停的网关缓存读取改为返回完全独立的深拷贝副本，消除内外层切片共享带来的潜在污染风险（属健壮性修复，现有调用路径均为只读，此前未发生实际故障）。

## 升级与验证边界

同一 Release 的瘦管理器 APK 与 Root 模块必须成套安装。回退时使用正式版 [v3.0.14](https://github.com/Wuwan94/wanBoxForAndroid/releases/tag/v3.0.14) 的 APK 和配套模块。发布证据（发布时按实际补齐：Preview Build run 号、合并提交、verify-android run 号）待发布后写入。本地 PreviewDebug APK 构建、528 项 JVM 单元测试与 AndroidTest Kotlin 编译已通过；Python 工具 108 项、版本与文档检查及 `git diff --check` 在本地通过。Android instrumentation 运行、最终发行双产物体积与 GitHub Verify CI 的本修复分支结果仍须独立补齐，不以编译成功替代执行结果。本版批次 4b、4c 因 GPT 中继账号失效，经用户批准由维护者亲自实现并自查，独立复审待通道恢复后补做——此点如实记录，不冒充已复审。未执行 Magisk / KernelSU / APatch 真机矩阵：图形化组编辑的完整应用链、资源页订阅更新、双向备份导入与模块退出诊断的真机表现仍未验证；自动化结果不等同于真实 Root 设备验证。
