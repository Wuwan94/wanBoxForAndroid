# v3.0.13-preview.4 验收与发布报告

**状态：已发布稳定性预览版（prerelease）。** [GitHub Release](https://github.com/Wuwan94/wanBoxForAndroid/releases/tag/v3.0.13-preview.4) 的 tag 指向 PR #21 合并提交 `d9f34202b9856b4cb151d8f4d52c532142e22e70`。正式稳定版仍为 `v3.0.11`；被替代的 `v3.0.13-preview.3` 已在新版本发布并核验后清理。

## 结果摘要

本轮修正了更新器离页后的任务生命周期和代理失败提示；瘦模式增加只读节点延迟探测；QS Tile 在 Connecting/Stopping 时不再切换，并以 fresh Root 状态和共享变更锁原子决策；分应用列表查询与可见图标加载移至后台。

PR #21 的应用代码提交 `46c342fb292c5e040e033bfc6c49742dcc4e7dc0` 通过 PR CI `42938060987` 与完整 Android/closeout run `42938103418`。包含发布说明隔离修正的最终 PR head `ffdfc8e96bbf851558bb81d0b669e8055b79765a` 又通过 [PR CI `42943516659`](https://github.com/Wuwan94/wanBoxForAndroid/actions/runs/42943516659) 和[完整 verify/closeout `42943570310`](https://github.com/Wuwan94/wanBoxForAndroid/actions/runs/42943570310)。这些检查都对应各自记录的精确 SHA；没有用旧 SHA 的本地通过结果代替远端 CI。

最终 closeout run 在 Android 35 x86_64 模拟器，以 preview.3（固定基线 `77e291a150819a70d87c0af8458f1c603088e432`）与 preview.4 完成旧版导出、旧→新导入、新版导出、新→旧导入四个方向，各为 `OK (1 test)`；制品中的三份数据文件 SHA256 也通过。此项仅为模拟器互通验证，不是 Root 真机验证。
