## 本轮改动

**更新任务生命周期与代理提示。** 切到后台时只关闭对话框，检查/下载继续；返回页面时恢复进度或交付已完成结果；只有 View 销毁时才取消任务并清理尚未交接的下载结果。取消后立即重试不会被旧 Job 槽位阻塞。更新流量仍只走本地 mixed 代理；代理不可用时失败关闭、不回退直连，并提供明确错误提示和手动打开 Release 页的入口。

**瘦模式节点测速。** 新增只读 `node tags` 查询，读取 Root 模块当前运行代次实际使用的 profile-tag 映射；Kotlin 只对映射内节点请求绑定 `127.0.0.1` 的 Controller delay API。请求使用 `Proxy.NO_PROXY`、Bearer 鉴权、限时与响应大小上限，不跟随重定向，也不切换活动节点；瘦 APK 保持不含核心 JNI。

**QS Tile 与分应用列表。** Tile 在 Connecting/Stopping 时不再发起启停；实际 toggle 前绕过 TTL 读取 Root fresh status，并在 RootModuleClient 共享 `changes` 锁内原子完成状态决策和服务动作。回归测试覆盖过渡态、稳定态、状态动作矩阵与互斥争用。分应用列表将包列表查询及可见行图标加载放到后台，复用 ViewHolder 前核对项目身份，并支持用户应用/系统应用过滤，系统分类包含更新过的系统应用。

**版本、预算与发布正文隔离。** 正式线不变；预览码为 `2024`，APK code 为 `10124`。硬门槛、预算脚本、基线元数据与回归测试统一为 **26 MiB（27,262,976 字节）**；远端完整 run 的 `Measure download budget` 步骤通过。新增 `prepare_preview_release_notes.py`，要求源码说明有未发布候选标题/状态，并仅在官方发布时去除此候选标记；对应单测确保公开正文不包含候选标题或状态段。

## 未完成与边界

**Root 真机矩阵未做。** 未在 Magisk、KernelSU、APatch 真机上验证安装、启停、Controller 连通和节点测速；本报告不声称真机测试通过。模拟器/JVM/静态检查不能替代 Root 真机签核。

**正式分发规则。** 正式签名下载资产必须由同一 `Preview Build` Release 流程构建并发布，在对应 Release 页成套提供 APK、普通 Root 模块、带管理器 Root 模块与 `SHA256SUMS`；不要将本地测量构建作为下载来源。
