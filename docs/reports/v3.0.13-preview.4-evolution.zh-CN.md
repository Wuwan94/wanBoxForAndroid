# v3.0.13-preview.4 体验收敛与瘦模式改进验收报告

**状态：独立分支候选，未合并、未发布。** 工作分支为 `wabi/preview4-evolution`，基线为已发布 tag `v3.0.13-preview.3`，commit `77e291a150819a70d87c0af8458f1c603088e432`。正式版本仍为 `3.0.11 / 2017`；预览元数据为 `3.0.13-preview.4 / 2024`，APK `versionCode=10124`。

## 结果摘要

本地构建的 PreviewRelease 测量 APK 与配套 Root 模块 ZIP 合计 **22,513,503 字节（21.47 MiB）**。按本轮更新后的硬上限 **26 MiB（27,262,976 字节）**，余量 **4,749,473 字节（4.53 MiB）**；绝对门禁与相对基线检查均通过。

Android JVM、Root 模块 Go、Python 工具和版本文档检查均通过。跨版本备份互通因无 KVM 模拟器未能启动 Android package 服务，仪器测试在安装前以 0 tests 失败；因此不声称备份格式已完成跨版本实机验证。

## 本轮改动

**更新任务生命周期与代理提示。** 切到后台时只关闭对话框，检查/下载继续；返回页面时恢复进度或交付已完成结果；只有 View 销毁时才取消任务并清理尚未交接的下载结果。取消后立即重试不会被旧 Job 槽位阻塞。更新流量仍只走本地 mixed 代理；代理不可用时失败关闭、不回退直连，并提供明确错误提示和手动打开 Release 页的入口。

**瘦模式节点测速。** 新增只读 `node tags` 查询，读取 Root 模块当前运行代次实际使用的 profile-tag 映射；Kotlin 只对映射内节点请求绑定 `127.0.0.1` 的 Controller delay API。请求使用 `Proxy.NO_PROXY`、Bearer 鉴权、限时与响应大小上限，不跟随重定向，也不切换活动节点；瘦 APK 保持不含核心 JNI。

**QS Tile 与分应用列表。** Tile 处理连接中/启停状态、Binder 断连或死亡、无效状态值和空节点名，并加入点击防抖与状态重读。分应用列表将包列表查询及可见行图标加载放到后台，复用 ViewHolder 前核对项目身份，并支持用户应用/系统应用过滤，系统分类包含更新过的系统应用。

**版本与预算口径。** 正式线不变；预览码推进到 `2024`，APK code 为 `10124`。硬门槛、预算脚本、基线元数据与回归测试现统一为 **26 MiB（27,262,976 字节）**。

**外部操作边界。** 本轮仅在独立分支提交并推送供复审；不创建 Release/Tag，不合并，不删除或改写现有 Release/Tag。
