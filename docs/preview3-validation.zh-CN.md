# v3.0.11-preview.3 验收记录

## 版本范围

本版以 preview.2 tag `2fbe17f662` 为基础，同时保留主分支已有界面。改动集中在后台配置查询、备份导入失败保护、服务启动错误上下文和 Root 模块状态处理，不新增代理模式或修改数据库 schema、备份格式及设置默认值。正式版历史说明保持不变。

## 自动化验收门禁

预览工作流在同一提交上执行 Root 模块 Go 测试与静态检查、Python 工具测试、Android/JVM 单元测试、Android 测试源码编译、安全检查，以及瘦管理器和 Root 模块构建。构建产物使用 `aapt`、`apksigner` 和模块 ZIP 检查包名、版本码、签名、ABI、模块版本与内容；候选校验器生成逐文件 SHA256 清单及验证报告。

Macrobenchmark 仅采集既有无 Baseline Profile 的测量基线；不因模拟器数字提交 Profile 或宣称提速。

## 发布与构件溯源

- 普通推送只运行构建与验证，不会创建公开 Release。
- 公开预览只能通过 main 上的人工工作流发布；输入的 `approved_sha` 必须与该次运行的 main 提交完全一致。
- 构建作业把经过身份、签名、模块和哈希验证的候选文件及报告上传为单一 `preview-candidate` 构件。发布作业只下载该次工作流运行产生的构件，核对来源提交、运行编号、版本标签、报告、文件哈希与原始 `SHA256SUMS`，不重建或重打包发布资产。
- 上传 Release 后先核对 Release 类型、标签目标提交和全部下载资产的大小与哈希；只有核验完成后才清理被替代的旧预览。正式版 Release 与 tag 不纳入清理范围。

## 兼容与安装

适用于 Android 12 及以上、arm64-v8a、已 Root 的设备。瘦管理器 APK 不包含核心，必须与同一发布页中的 Root 模块配套使用；升级前建议导出配置备份并保存到设备之外。下载资产应按发布页提供的 `SHA256SUMS` 校验。

已知未扩展范围：Balancer 子页的其他同步查询；`applyBackend` 清理异常可能覆盖原始错误。当前变更未将这两项风险扩大为“全路径均已解决”的结论。
